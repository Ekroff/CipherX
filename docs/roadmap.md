# CipherX – Product Roadmap

## v1.0 (Current Release)
- ✅ CBOM Discovery Engine (JS, Python, Java, Go)
- ✅ AST-based cryptographic scanning
- ✅ AI-powered risk analysis (OpenAI GPT-4o)
- ✅ AI-powered code remediation
- ✅ CI/CD Gatekeeper (GitHub/GitLab webhooks)
- ✅ Compliance mapping (OWASP, NIST, PCI-DSS, ISO 27001)
- ✅ JWT authentication + RBAC
- ✅ Multi-tenant architecture
- ✅ API Gateway with rate limiting
- ✅ Docker Compose dev environment
- ✅ Kubernetes + Terraform deployment

## v2.0 (Q3 2026)
- 🔲 **Language Expansion**: C/C++, Rust, C#, Swift, Kotlin
- 🔲 **Container Scanning**: Dockerfile & image layer analysis
- 🔲 **IaC Scanning**: Terraform, CloudFormation, Pulumi
- 🔲 **SBOM Integration**: SPDX and CycloneDX format support
- 🔲 **SSO/SAML**: Enterprise identity provider integration
- 🔲 **Grafana Dashboards**: Pre-built monitoring dashboards
- 🔲 **Slack/Teams Notifications**: Real-time alerting
- 🔲 **API Key Management**: Self-service API key rotation
- 🔲 **Webhook Subscriptions**: Event-driven notifications
- 🔲 **Data Retention Policies**: Configurable finding archival

## v3.0 (Q1 2027)
- 🔲 **Real-time Scanning**: File system watchers for continuous monitoring
- 🔲 **Custom Detection Rules**: User-defined crypto pattern rules
- 🔲 **Risk Trending ML**: Machine learning risk prediction
- 🔲 **Multi-Cloud IaC**: Azure, GCP Terraform modules

- 🔲 **IDE Plugins**: VS Code, JetBrains, Vim extensions

- 🔲 **White-label Platform**: Reseller-ready branding
